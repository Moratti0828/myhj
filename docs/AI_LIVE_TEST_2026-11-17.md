## 结论与范围

本轮使用真实硅基流动和阿里云百炼 Key，通过已登录的项目 HTTP / SSE 接口完成有限样本验收。识图、在线书童、异步绘图、普通转绘、精修、构图候选评分、三组故事提案、图生视频、画廊保存及重启恢复均有实际结果。接口通路通过不代表每个生成样本的艺术质量合格。

真实 AI 运行在本机隔离 JSON 数据目录；真实 MySQL 另以集成测试验证。正式本地预览服务已加载真实 API 配置并连接 MySQL。本轮未执行完整浏览器自动化或公网验证，不将接口实测写作全场景验收。

## 实测发现与修复

1. 书童把“不需要生成图片”误判为绘图，已增加明确否定优先规则。
2. 同一次书童请求被两次额度检查，导致任务发出后返回 429；已移除重复检查，回归验证一次请求仅预扣一次。
3. 本机代理 Fake-IP DNS 将图片域名解析为 198.18.*，触发保留地址保护。新增可选 IMAGE_DNS_OVER_HTTPS=true，使用固定公共 DoH 解析，仍验证公网地址、钉扎 IP 并验证 TLS；默认关闭。
4. 供应商返回 application/octet-stream 图片，旧规则拒绝下载。现允许此 MIME，但仍限制体积、像素并通过 sharp 实际解码判定格式。
5. 精修提示词原来无条件强调手写字保留，现明确只有原图存在文字才保留，禁止新增题字、印章及签名；明确现有主体不得删除或复制。本次同时明确了用户修改意图，改善结果不能全归因于单一提示词修改。

免费回归：npm test 全部通过（含 13 项后端回归、视频 Mock、结构、编排、叙事和前端状态）；JSON HTTP 35 项通过；真实 MySQL 数据库测试及 MySQL HTTP 35 项通过。模型回归使用本地 Mock，不额外计费。

## 效果边界

- 结构评分只测部分几何指标。1.000 分样本仍出现像新增小舟的倒影，不能称为艺术质量满分或语义完全保真。
- 视频抽帧出现原图不存在的印章、云纹和明显月轮变化，未满足严格的原画保持要求；记录为效果不足，不作为优秀成片宣传。
- 故事三案均围绕月影伴舟，叙事差异性仍需优化。
- 精修修订仅复验一个样本，不保证其他输入都不丢主体、不增字。
- 未测：真实自动返修、多次随机种子、全部风格、视频有声与 1080P 档、压力／多用户并发、全流程浏览器交互及公网部署。
