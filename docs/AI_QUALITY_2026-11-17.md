## 原作保真

系统对照原图与候选图，检查主体数量、身份、题字和印章。默认使用 Qwen/Qwen3-VL-32B-Instruct；复核结论与几何结构分共同参与候选选择。主体缺失等有证据的语义错误优先于总分处理。

线稿转绘与成画精修采用不同规则：转绘允许合理的树冠、山体与倒影补全，精修保持更严格的主体约束。普通生成与精修仅在复核通过后交付新图，其他情况保留原作品。构图返修重新使用原始草图，每轮最多四次图像调用。

## 视频表现

“保真优先”使用 wan2.6-i2v，默认 1080P 档、5 秒、含音轨；“快速预览”保留低成本模型。提示词围绕原作已有元素和轻微运动组织。页面展示模式、清晰度和费用差异，成片由用户确认后保存。

山水小舟实测样片约 5.007 秒、1440×1440。五张等间隔抽帧与中间帧检查中，主要构图和主体保持，未见额外印章与云纹；全文件解码通过。该结论针对本次抽样画面。

## 工程验证

- 类型检查与生产构建通过。
- npm test 通过，含 16 项后端回归及 Mock、结构、编排、叙事和前端状态测试。
- JSON HTTP 35 项断言通过。
- 真实 MySQL 集成与 MySQL HTTP 35 项断言通过。
- 浏览器确认视频默认参数与质量模式提示。

质量控制采用“几何评价、语义复核、用户确认”三层流程。模型判断辅助筛选，最终展示作品由创作者审阅选择。
